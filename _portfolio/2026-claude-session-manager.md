[Claude Session Manager](https://github.com/jeromezliu/claude-session-manager) is a native SwiftUI macOS app for the `.jsonl` transcripts that Claude Code stores under `~/.claude/projects`. It lists sessions across projects, shows their content, and lets you rename, archive or delete them in bulk.

Distributed through a personal Homebrew tap (`brew tap jeromezliu/tap && brew install --cask claude-session-manager`) and as signed release zips on GitHub.
