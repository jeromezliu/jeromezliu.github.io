[maps.rwx2.com](https://maps.rwx2.com) is a static single-page app for comparing map vendors side by side. Drag, zoom or rotate any pane and the others follow. One control panel drives place, address and coordinate search, directions, live traffic and a shared current location across every visible map, and a right-click on any map copies coordinates or starts a route from that point.

Built with React 19, Vite, TypeScript, MapLibre GL, Mapbox GL JS and the TomTom Maps SDK for JavaScript. There is no backend: you bring your own API keys, which stay in the browser. Deployed on Azure Static Web Apps with GitHub Actions.
